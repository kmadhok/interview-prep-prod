## About the role

As an Ontology and Knowledge Graph Engineer in Chase's Data and Analytics Office, you will curate the semantic data assets that connect our enterprise data estate to a shared, intelligent knowledge graph. Work at the intersection of formal knowledge representation, logical data modeling, and data integration — building ontologies and mapping assets that make data semantically interoperable across use cases. Contribute to a foundational capability that underpins enterprise AI, analytics, and data governance.

## Responsibilities

- Author Logical Data Model Ontologies composing concepts from Upper Ontologies and Semantic Taxonomies to represent how enterprise data is materialized.
- Design and maintain Knowledge Graph Mapping assets connecting relational DBs, REST APIs, in-memory structures, and real-time streaming sources to a coherent enterprise knowledge graph.
- Curate Semantic Taxonomy structures using controlled vocabularies and Concept Schemes.
- Contribute to design/governance of Upper Ontologies and Semantic Taxonomies (the shared conceptual backbone).
- Enable Virtual Knowledge Graph capabilities (on-the-fly KG materialization without physical data movement).
- Engage with data architects, domain SMEs, AI engineers, and ML engineers to align ontology/mapping design with physical data structures and downstream Reasoning / Semantic Validation.
- Participate in ontology governance (versioning, change management, deprecation, cross-domain alignment).
- Translate complex business/data requirements into formal semantic representations that are technically rigorous and accessible to non-technical stakeholders.

## Required qualifications

- 1 year working with semantic web technologies, knowledge graph engineering, ontology development, or linked data (professional or research).
- Understanding of formal knowledge representation (class hierarchies, property definitions, logical constraints).
- Familiarity with data mapping concepts connecting structured/semi-structured sources to ontology-defined target vocabularies.
- Working knowledge of semantic data model layers (foundational data models, schema definition languages, controlled vocabulary organization).
- Exposure to relational DBs + semi-structured sources (REST APIs, in-memory, streaming).
- Ability to translate business/data requirements into formal semantic models.
- Awareness of Virtual Knowledge Graph concepts.

## Preferred qualifications

- Hands-on authoring of ontologies + KG mapping assets in a production enterprise environment.
- Experience with enterprise-scale KG programs.
- Reasoning / Semantic Validation frameworks (syntactic/semantic correctness).
- Upper Ontology design patterns.
- Communicating semantic modeling to non-technical stakeholders.
- Real-time streaming integration into KG pipelines.
- Ontology governance (versioning strategies, cross-domain alignment).
