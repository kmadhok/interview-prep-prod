## Relevant project

**Registry-governed semantic layer (Walmart Data Ventures).** Business teams kept re-deriving metric logic and filing tickets for routine questions. I built a semantic layer over BigQuery where YAML definitions plus vocabulary snapshots define the legal dimensions, values, and table wiring (16 governed demographic dimensions, 5 output types). A single LLM call maps a question to strict JSON intent — the model never writes SQL — then a deterministic gate validates and canonicalizes the intent and a deterministic compiler emits the SQL, so the same question returns the same answer every time. New or changed definitions pass a human review gate before entering the registry. It converted 30–60 minutes of analyst execution per covered request into product-led self-service.

**Governed BI at scale (Walmart Data Ventures).** Delivered 5 Power BI dashboards ranked top 1.4% of Walmart's 207,000 dashboards (1,064 views, 22 users), cutting data-request turnaround from 1–24 hours to 5–10 minutes; recognized with a Making a Difference Award.
