## About the role
Pinterest is building a new capability: embedding AI-native engineering directly inside business functions. The AI Solutions Engineer partners with teams across Marketing, Finance, Sales, HR, Legal and other functions to surface high-value automation opportunities, then designs and ships the AI-powered tools that bring them to life. Hands-on, mid-level software engineering role — equally comfortable reading a business process flowchart and writing production-grade Python. End-to-end: discovery and scoping through prototyping, launch, and iteration, using the latest agentic frameworks, tool-calling patterns, and responsible AI practices.

## What You'll Do
- Discover and scope AI opportunities with internal corporate-function teams; map/improve business processes, identify bottlenecks, propose AI-enabled changes with clear business outcomes (time/cost savings, quality/compliance).
- Design end-to-end AI solutions that integrate with existing systems and data, intuitive for non-technical users.
- Build and ship production-quality software: clean code + tests, CI/CD, logging, monitoring, guardrails.
- Pilot, roll out, and drive adoption with end-users; gather feedback and iterate.
- Champion responsible AI (privacy, security, compliance; sensitive/regulated data).
- Build for reuse: reusable patterns, components, documentation.
- Accelerate workflows with generative AI and automation.

## What We're Looking For
- Software engineering foundation; ability to build and operate production systems (backend services, internal tools, integrations, data apps).
- Hands-on AI/automation delivery — shipped AI-powered or automation-driven solutions (multi-step workflow automation, document understanding/intelligent routing, integration of an AI service like OpenAI, Anthropic, Vertex AI, Bedrock).
- Agentic AI literacy: local vs remote agents, how MCP (Model Context Protocol) works, what Agent Skills and Hooks are for, A2A coordination; reason about when to use these patterns.
- System design & architecture: data flow, integration points, trade-offs, design for failure (fallbacks, retry logic, timeouts, human escalation).
- Data and security judgment: access controls, PII minimization, audit logging, filter data before it reaches the model.
- Business function acumen: engage credibly with Marketing/Finance/Sales/HR/Legal/Operations stakeholders; understand workflows, KPIs, constraints.
- Clear, collaborative communication: explain architecture trade-offs to a Finance Manager and debug a prompt failure with an engineer the same afternoon.

## Preferred
- Embedded with corporate/G&A functions (Finance, Legal, HR, Marketing, Sales Ops).
- Agentic frameworks (LangGraph, Claude Agent SDK, or comparable).
- MCP server design — building, deploying, securing MCP-compliant tool servers.
- Designing/evaluating AI outputs at scale: eval sets, sampling pipelines, human-in-the-loop review queues, A/B testing.
- Responsible AI frameworks; RAG pipelines, vector databases, enterprise search.
- CI/CD for AI: prompt versioning, model version pinning, regression testing for LLM features.
