# Job Search Target Profile

_Last updated: 2026-05-28_
_Derived from the 13 JDs filed in this workspace + active pipeline + recent archetype-interest signals._

---

## The role, in one paragraph

**Senior-IC Forward-Deployed AI / Agent-Builder role where I ship production agentic systems end-to-end against real business outcomes — with a strong bias toward startups building agents that talk to data.**

I want to be the person who takes a messy business problem, designs an agent or agentic workflow to solve it, builds it in Python with Claude/MCP/LangGraph-class tooling, validates it with rigorous evals, ships it to a real user, and owns the outcome. Customer-embedded or business-embedded — not insulated IC, not pure research, not pure DS. Senior individual contributor; no management track.

---

## Non-negotiables

- **End-to-end ownership** — scoping → build → eval → deploy → adoption
- **Agentic systems work** — LangGraph / multi-agent / MCP / tool use / RAG as the core craft, not a side note
- **Translation work** — ambiguous business problem → working software → executive narrative
- **Hands-on building**, not strategy decks
- **Senior individual contributor**, not people-management

## Interview format preference

**Strong preference for leetcode-free loops.** My edge is end-to-end agent building, business translation, and shipped systems — not DSA puzzles. Roles that screen on leetcode usually also screen for the wrong kind of work for me (insulated SWE, abstract problem-solving over customer outcomes), so this filter doubles as a fit filter.

### Companies / role types that almost never use leetcode (target these)

1. **Forward-deployed / Applied / Solutions engineering at AI labs** — Anthropic FDE, Cohere FDE, OpenAI Solutions/Value Engineer, Snorkel FDE, Cognition AI Enablement. Loops are case studies, take-homes, live agent-build exercises, business translation.
2. **Seed / Series A–B agent startups (≤100 people)** — Meticulous, Jack & Jill, Hebbia, Julius, Numbers Station, Seek AI, early Hex/Glean. Loops are take-home + system design + founder chat.
3. **In-house "Agent Builder" / "Applied AI" at enterprise & financial** — Walmart Agent Builder (confirmed no leetcode), Harrison Street, H.I.G., Morningstar. Loops are behavioral + case + architecture whiteboard.
4. **Consulting-house agentic AI builders** — BCG X, Deloitte FDE, Capgemini, PwC, Accenture AI. Consulting shape (case + behavioral + portfolio walkthrough), no DSA.

### Companies / role types that almost always DO use leetcode (skip even if title sounds right)

- **Big tech AI orgs** — Google, Meta, Amazon, Apple, Microsoft. Even "Applied AI" routes through standard SWE loop.
- **FAANG-adjacent / heavily-funded infra** — Databricks, Snowflake, Stripe, Airbnb, Pinterest core SWE.
- **OpenAI engineering (non-Solutions)** — SWE leetcodes; Solutions/FDE side mostly doesn't.
- **Quant shops** other than FDE-style — Two Sigma, Citadel, Jane Street.

### Signals in the JD itself

**Leetcode-free tells:** "Forward Deployed" / "Applied" / "Solutions" / "Customer-embedded" in title · "Translate ambiguous business problems" · "Build with customers on-site" · "Portfolio of agentic systems" or "demo your work" · company <200 people.

**Will-leetcode-you tells (even if title sounds agent-y):** "Strong CS fundamentals" / "algorithms & data structures" explicit in JD · big-tech parent · "Engineering" team without "Applied" / "Solutions" / "Forward Deployed" prefix · JD mentions "coding interview" generically.

## Structured search filters

Apply to every `search_jobs` call. Use as a hard pre-filter where the MCP supports it, and as a read-time post-filter otherwise.

### Seniority

- **Include:** Senior, Staff, Principal — all IC track
- **Skip:** Manager, Director, Lead-with-reports, Junior, Mid, Intern

### Location

- **In scope:** San Francisco · New York · Los Angeles · Chicago · Remote (US)
- **Hybrid / on-site:** fine in the four cities above
- **Skip:** any other on-site-required location

### Compensation floor

Geo-adjusted base floors:

| Geo | Base floor |
|---|---|
| NYC · SF · LA (high COL) | **$170k+** |
| Chicago · Remote-US · other lower-COL | **$140k+** |

- **Total comp:** prefer $200k+ where visible, but don't hard-filter on it
- Adjust down only for seed/Series A where equity meaningfully compensates

### Company size

| Band | Pull |
|---|---|
| <200 employees | **Strong pull** — closest to "the thing I want to build" |
| 200–2,000 | Acceptable |
| 2,000–50,000 | Acceptable only if title is FDE / Applied / Solutions / Agent Builder |
| >50,000 | Skip unless title is explicitly FDE / Applied / Solutions / Agent Builder |

### Funding stage (private cos)

- **Strong pull:** Seed · Series A · Series B · Series C
- **Acceptable:** Series D+, late-stage private
- **Skip default:** post-IPO unless FDE / Applied / Solutions title

### Recency

- **Default:** posted in last 14 days
- Widen to 30 days only if Tier 1 queries return <10 results

### Hard-skip company list (don't even read the JD)

Google · Meta · Amazon · Apple · Microsoft · Databricks · Snowflake · Stripe · Airbnb · Two Sigma · Citadel · Jane Street

*Exception:* if title contains "Forward Deployed" / "Applied AI" / "Solutions Engineer" explicitly, read the JD before skipping.

- "model training" / "pre-training" / "post-training" as main verb

- "Spark / dbt / Airflow pipeline" with no agent layer
- "strong CS fundamentals" / "algorithms & data structures" (leetcode tell)
